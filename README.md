# LogPhoto — iPhone 16 Pro 向け Log写真 試作

動画の Apple Log を静止画でも使うためのカメラアプリ試作です。

## 撮影モード
- **Logフレーム（方式A）**: Apple Log のビデオフレームを、シャッター時に写真として保存します。
- **RAW+Log（方式B）**: Bayer RAW で撮影し、DNG をそのまま保存します。あわせて RAW を現像し、Log カーブ（近似）で変換した JPEG も保存します。

## v1.12 の変更
- 画面構成を純正カメラ寄りに変更
  - 倍率チップ（0.5 / 1x / 2 / 5）をシャッター上に常時表示。チップ上を左右にドラッグ、
    またはプレビューをピンチすると、その間だけスライダーが現れ、1.5 秒後に自動で消える
  - 倍率と AF 状態の読み出しは上部に常時表示
  - 形式 / 画角 / LUT / グリッド / マクロ / 露出 / マニュアル / 撮影モードは
    右下の歯車ボタンで出てくる下半分のシートに集約（プレビューは見えたまま）
  - マニュアル（SS / ISO / 焦点 / WB）は小さなパネルにしてプレビューを隠さない
  - シャッター音を追加（純正と同じ音。マナーモードでは鳴らない）
  - アプリアイコンを昔の iOS 風（革張りボディ＋クロームとガラスレンズ）に変更
- レスポンス改善: ピンチ/スライダーのズーム要求をまとめて最新だけ適用し、表示倍率は即時更新。
  レンズ切替は入力の付け替えとフォーマット設定を 1 回のセッション再構成にまとめ、
  デバウンスを 0.3 秒 → 0.15 秒に短縮
- Log の検証表示: 上部バッジは「実際に activeColorSpace が Apple Log か」を示す
  （違えば「⚠︎ LOG 無効」）。読み出しにレンズ名とフレームの画素形式（x422 など）を表示し、
  保存メッセージにも Log 有効/無効を含める。Log フレームの TIFF は 16bit 書き出し
- RAW+Log とレンズ切替のバグ修正
  - 切替時に Log 用 → RAW 用とフォーマットを二重に変えていたのをやめ、モードとデバイスから
    一度で決めるようにした（ちらつき/真っ暗の原因）
  - 進行中の RAW ポーリングをトークンで無効化し、古いポーリングが新しい構成を壊さないようにした
  - ズーム操作のたびに RAW セットアップが再試行され、失敗時に点滅ループしていたのを修正
  - 撮影時の例外クラッシュ対策（photoQualityPrioritization の上限設定、フォーマット変更後の
    maxPhotoDimensions 更新。RAW→Log 変換のメモリ負荷を抑えるため写真サイズは 13MP 程度まで）
  - RAW 撮影は DNG と Log 変換画像の 2 枚にした（以前は HEVC も含めて 3 枚保存されていた）
- 望遠レンズ（5x）を追加。Apple Log は実カメラでしか使えないため、これまでの「5」は広角の
  デジタルズームだった。表示倍率に応じて 超広角 / 広角 / 望遠 を切り替える
  （RAW 撮影の変換画像はデバイス倍率でトリミング）
- タップ AF 後にシーンが変わったら自動 AF/AE に戻るようにした（純正と同じ挙動）

## v1.12 build 14〜22 の変更（実機検証しながら）
- Apple Log が外れていた問題を修正（session.automaticallyConfiguresCaptureDeviceForWideColor を OFF）
- RAW 撮影のクラッシュを修正。AVFoundation の規則で Bayer RAW は
  photoQualityPrioritization = .speed かつ videoZoomFactor = 1.0 が必須。RAW モードでは
  デバイスの倍率を 1.0 に固定し、倍率はプレビューのクロップで表現する
- 方式Bの Log 変換を Apple Log の公式 OETF（Apple Log Profile White Paper）に置き換え、
  BT.2020 原色で符号化。Core Image のフィルタ連鎖では符号値が狂ったため CPU で画素ごとに計算
- RAW を 48MP で撮れるようにした（設定の 12MP / 48MP）。変換は横帯ごとに処理してメモリを抑える
- LUT は既定で「表示のみ」（保存は Log のまま）。「保存にも」で焼き込み
- 望遠は被写体が最短距離より近いと広角のクロップへ自動で逃がす（純正と同じ）
- 4:3 は純正と同じくプレビューを上に寄せ、下の黒い領域に操作系を置く配置
- シャッター音の ON/OFF、RAW 撮影の段階記録（落ちた段階を次回起動時に表示）

## v1.13 の変更
- 望遠（5x）の近距離: 切替直後にも AF の位置を確認し、最短距離より近ければ即座に広角の
  5x クロップへ。往復しないよう自動復帰は 1 回まで（5x チップを押し直すと再試行）
- マニュアル設定（SS / ISO / 焦点 / WB）をレンズ切替・モード切替後も維持し、新しいレンズの
  範囲にクランプして再適用。露出補正もレンズ切替後に掛け直す
- マニュアルのプリセット 5 枠（タップで呼び出し、長押しで保存 / 上書き / 削除。再起動後も保持）
- マニュアルバーは設定パネルの上に積み、設定を閉じるとその位置まで下にスライド。
  どちらも倍率チップとシャッターを隠さない
- 露出補正の範囲を端末の上限いっぱい（16 Pro は ±8EV）に
- スライダーは各行のダブルタップで初期値へ。設定に「すべて初期値に戻す」
- グリッドに中央の縦線を追加（既定で表示）

> 方式Bの Log 変換は Apple Log の OETF を使っていますが、RAW 現像の露出尺度（18% グレーの位置）は
> 実機で確認中です。保存メッセージに出る 黒 / 中央 / 白 の符号値で判断できます。

## ビルド（Macなし・無料クラウド）
このリポジトリに push すると GitHub Actions が自動でビルドします。
- Actions タブの「Build (unsigned, compile check)」が緑 = コンパイル成功
- 仕組み: クラウドMac上で XcodeGen が `project.yml` から Xcode プロジェクトを生成し、
  署名なしで `xcodebuild` を実行します

## 注意
- このビルドは署名なし（コンパイル確認専用）です。
  iPhone 16 Pro 実機に入れるには Apple Developer Program（$99/年）での
  署名 + TestFlight が別途必要です。
- Bundle ID は仮で `com.example.logphoto` です。

## 構成
- `*.swift` — アプリ本体（SwiftUI + AVFoundation、Apple Log は第1世代）
- `project.yml` — XcodeGen 用プロジェクト定義
- `.github/workflows/build.yml` — 無料クラウドビルド設定
